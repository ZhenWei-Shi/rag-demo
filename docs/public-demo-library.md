# NOVA Library — Synthetic Demo Handbook

This fictional handbook is public sample data for the RAG demonstration. It does not describe a real institution.

NOVA Library closes at 18:30 on Fridays. Book loans last 21 days. Membership costs 17 dollars per year. Members should contact the circulation desk to renew a loan.

This handbook does not specify the director's name or the year the library was founded. If asked for these details, say that the document does not provide them.
